## 1. GA4 — 맞춤 정의 등록 (⚠️ 최우선 · 소급 안 됨)

**관리 → 데이터 표시 → 맞춤 정의 → 맞춤 측정기준/항목 만들기**
등록 시점 **이후** 데이터만 탐색에 나타나므로 **오늘 바로** 등록.

- [ ] `source` → 맞춤 측정기준, 범위=이벤트, 이름 `source`
- [ ] `product_id` → 맞춤 측정기준, 이름 `product_id`
- [ ] `label` → 맞춤 측정기준, 이름 `outbound_label`
- [ ] `content_name` → 맞춤 측정기준, 이름 `content_name`
- [ ] `menu_name` → 맞춤 측정기준, 이름 `menu_name`
- [ ] `section` → 맞춤 측정기준, 이름 `section`
- [ ] `seconds` → 맞춤 **측정항목**, 이름 `dwell_seconds`, 측정 단위=표준
- [ ] (정리) v1 잔재 측정기준(`device` 등) 보관처리(archive)

## 2. GA4 — 실발화 검증 (DebugView, 즉시)

탐색은 24~48h 지연이므로 재구축 전에 먼저 확인.

- [ ] 크롬 확장 **GA Debugger** 켜고 `https://www.newed.kr` 접속 → GA4 **관리 → DebugView** 연결
- [ ] `page_view`가 라우트 이동마다 1건씩(자동 page_view 중복 없음)
- [ ] `outbound_click` 발화 시 `label`·`source`(·`product_id`) 파라미터 값이 §0 표대로 들어오는지

- [ ] `section_*` 이벤트에 `seconds`가 붙는지 (1초 미만 스침은 미전송이 정상)

## 4. GA4 — 탐색(Explore) 보고서 재구축

**탐색 → 빈 탐색 생성**. 각 보고서 아래 설정대로.

- [ ] **① 카카오 전환 경로별**
  - 이벤트 필터: `outbound_click`, 조건 `outbound_label = shop`
  - 행: `source` (`menu`·`icon`·`product_more`·`hero`·`buybutton_*`)
  - 값: 이벤트 수
- [ ] **② 상품별 구매의도**
  - 필터: `outbound_click` + `outbound_label = shop`
  - 행: `product_id` (`deep`·`bright`·`decaf`)
  - 값: 이벤트 수
- [ ] **③ 인스타 문의 위치별**
  - 필터: `outbound_click` + `outbound_label = instagram`
  - 행: `source` × `page_path`
  - 값: 이벤트 수
- [ ] **④ 섹션 체류 (v1 dwell 대체)**
  - 이벤트: `section_*`
  - 행: `section`
  - 값: `dwell_seconds` 평균, 이벤트 수
- [ ] **⑤ 인기 제품(카드 클릭)**
  - 이벤트: `product_click`
  - 행: `product_id`
  - 값: 이벤트 수
- [ ] **⑥ 콘텐츠 조회(ViewContent)**
  - 이벤트: `view_content`
  - 행: `content_name` × `source`
  - 값: 이벤트 수

> 새로 만든 맞춤 측정기준이 변수 목록에 안 보이면 등록 후 24h 미경과 or 데이터 미유입. DebugView에서 값이 보이면 시간이 해결.
